# L2web - 個人即時儀表板 & 全台氣象觀測

本專案為課堂實作項目，結合現代前端玻璃擬態（Glassmorphism）動態設計，串接交通部中央氣象署（CWA）Open Data API，提供全臺 22 縣市未來 36 小時預報、臺灣時間與即時氣象圖資。

## 🌟 功能特色

1. **台北標準時間（Asia/Taipei UTC+8）**
   - 毫秒級即時時鐘更新
   - 包含秒數動態進度條與呼吸狀態燈

2. **🗺️ 臺灣縣市動態氣象視覺化**
   - 使用實際縣市邊界製作互動式溫度分級圖，包含馬祖、金門與澎湖外島視窗
   - 全臺 22 縣市依首時段預報均溫變換色彩（藍／綠／黃／紅）
   - 支援滑鼠、觸控與鍵盤操作，點選縣市後聯動右側面板顯示 36 小時三階段預報

3. **🛰️ 中央氣象署 (CWA) 即時高解析圖資中心（全新功能）**
   - **臺灣雷達回波合成圖**（`CV1_TW_3600.png`）：即時降雨水氣強度與對流胞路徑
   - **彩色紅外線衛星雲圖**（`LCC_IR1_CR_2750.jpg`）：高低空雲系、雲頂溫度與鋒面位置
   - **全台即時氣溫分佈圖**（`temp.jpg`）：自動氣象站實測等溫線分佈
   - **廣域雷達整合圖**（`CV1_3600.png`）：包含臺灣海峽及鄰近海面水氣

4. **中央氣象署（CWA）官方 API 即時資料串接**
   - 串接 `F-C0032-001` 三十六小時天氣預報開放資料
   - 計算首時段全臺預報均溫、最高／最低預報及最高降雨機率
   - 具備 10 秒逾時、回應完整性檢查、錯誤提示與最近成功資料快取

5. **多模式觀測切換**
   - 🗺️ 台灣地圖觀測模式
   - 🛰️ 即時衛星/雷達圖資中心
   - 🗂️ 全台列表卡片模式（支援分區篩選與關鍵字即時搜尋）

6. **現代視覺設計**
   - 採用 Dark Mode 深色玻璃擬態（Glassmorphism）質感
   - 背景三色動態平滑光暈動畫與顆粒感紋理
   - 響應式佈局（適配桌面螢幕、平板與手機）

## 🚀 技術棧

- **HTML5 / CSS3**：原生 Vanilla CSS，自定義漸層、動態特效與響應式 Grid/Flexbox 佈局
- **JavaScript (ES6+)**：非同步 Fetch API、即時 Date 物件處理、動態 DOM 渲染
- **數據來源**：[交通部中央氣象署氣象資料開放平臺](https://opendata.cwa.gov.tw/)
- **字型**：Google Fonts (Outfit, JetBrains Mono, Noto Sans TC)
- **部署平台**：GitHub Pages

## 📊 資料說明

- 縣市天氣資料來自 CWA `F-C0032-001`，屬於未來 36 小時預報，不是測站即時觀測溫度。
- 雷達、衛星與氣溫圖資於切換至圖資頁面後才載入，以降低首頁流量與行動裝置記憶體使用量。
- 臺灣縣市邊界衍生自 [g0v/twgeojson](https://github.com/g0v/twgeojson)，採 CC0 1.0 公眾領域授權並簡化後內嵌使用。
